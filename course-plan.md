
# Java Start: fundamentos de Java para principiantes

## 1. Resumen del curso
Java Start es un curso introductorio de Java dirigido a estudiantes de 12 a 17 años sin experiencia previa.
El curso utiliza videojuegos como temática común y desarrolla progresivamente un registro orientado a objetos. Todos los ejemplos y actividades pueden ejecutarse desde un navegador mediante JDoodle.

**Repositorio de código fuente:** [Abrir repositorio en GitHub](https://github.com/upc-pre-202620-1asi0729-7750-cleancode/java-fundamentals-course-maquigest)

## 2. Público objetivo

Estudiantes de secundaria de 12 a 17 años interesados en aprender programación desde cero.
No se asume experiencia previa con Java ni con otros lenguajes de programación.

## 3. Prerrequisitos

- Manejo básico de un navegador web.
- Conexión a Internet.
- Capacidad para copiar, modificar y ejecutar código.
- No se requiere instalar Java.
- No se requiere un entorno de desarrollo local.

## 4. Objetivo general

Construir un registro básico de videojuegos aplicando sintaxis de Java, variables, entrada y salida, operadores, condiciones, arrays, bucles, funciones auxiliares, clases, objetos y encapsulación.

  

## 5. Objetivos de aprendizaje

Al finalizar el curso, el estudiante podrá:  

1. Reconocer la estructura básica de un programa Java.

2. Mostrar información en la consola.

3. Declarar variables con diferentes tipos de datos.

4. Solicitar información mediante `Scanner`.

5. Aplicar operadores y conversiones.

6. Construir decisiones con `if`, `else if` y `else`.

7. Almacenar información en arrays.

8. Recorrer arrays mediante bucles.

9. Utilizar `while` para mantener activo un proceso.

10. Crear funciones auxiliares con parámetros y valores de retorno.

11. Diferenciar funciones `void` y funciones con retorno.

12. Definir clases, atributos y constructores.

13. Crear objetos y llamar métodos de instancia.

14. Aplicar encapsulación con atributos privados, getters y setters.

15. Validar entradas numéricas.

16. Integrar los conceptos en un programa funcional.

  
  

## 6. Proyecto transversal
El proyecto transversal es un registro de videojuegos.
Durante las lecciones se desarrollan progresivamente sus elementos:
- Mensajes en consola.

- Datos de un videojuego.

- Clasificación mediante puntuaciones.

- Catálogo almacenado en arrays.

- Recorrido y consulta de información.

- Organización mediante funciones.

- Modelado con clases y objetos.

- Validación y encapsulación.

En la versión final, el usuario selecciona una cantidad de 1 a 10 videojuegos. El programa registra cada juego, valida sus datos y muestra un catálogo completo.
